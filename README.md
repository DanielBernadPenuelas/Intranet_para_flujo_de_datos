# Intranet para Flujo de Datos
 
Aplicación frontend moderna construida con React y Vite para gestionar, monitorear y optimizar el flujo de datos dentro de la organización. Proporciona una interfaz intuitiva para visualizar pipelines de datos, métricas de procesamiento y facilita la colaboración entre equipos de datos.
 
## Descripción General
 
Intranet para Flujo de Datos es una plataforma web interactiva que permite a los usuarios:
- Visualizar dashboards en tiempo real con métricas de datos
- Monitorear el estado de pipelines de procesamiento
- Acceder a reportes y estadísticas detalladas
- Gestionar configuraciones de flujos de datos
- Colaborar en proyectos relacionados con datos
## Características Principales
 
- Interfaz moderna y responsiva construida con React 19
- Dashboards interactivos y personalizables
- Visualización de métricas en tiempo real
- Navegación intuitiva entre módulos
- Soporte para múltiples navegadores modernos
- Optimización de rendimiento con Vite
- Validación de código con ESLint
## Requisitos del Sistema
 
### Software
- Node.js >= 14.0.0
- npm >= 6.0.0
### Navegadores Soportados
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+
## Instalación
 
### 1. Clonar el Repositorio
 
```bash
git clone https://github.com/DanielBernadPenuelas/Intranet_para_flujo_de_datos.git
cd Intranet_para_flujo_de_datos
```
 
### 2. Instalar Dependencias
 
```bash
npm install
```
 
### 3. Iniciar en Modo Desarrollo
 
```bash
npm run dev
```
 
La aplicación estará disponible en `http://localhost:5173` (puerto por defecto de Vite)
 
### 4. Construir para Producción
 
```bash
npm run build
```
 
Los archivos compilados se guardarán en la carpeta `dist/`
 
### 5. Vista Previa de Producción
 
```bash
npm run preview
```
